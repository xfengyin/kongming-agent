# 隆中对

刘备三顾茅庐，诸葛亮提出隆中对：先取荆州为家，再取益州成鼎足之势，
然后待天下有变，两路北伐以图中原。核心是先建立根据地，再图进取。

# 空城计

司马懿大军压境，诸葛亮大开城门，焚香抚琴。司马懿疑有伏兵，退兵而去。
启示：信息不对称时，镇定与示弱可以扭转局势。

# 草船借箭

诸葛亮立军令状三日造十万支箭，趁大雾以草船诱敌，曹军射箭如雨，
尽收箭支，不费吹灰之力。启示：善用天时与资源置换。

# 木牛流马

诸葛亮发明木牛流马运粮，解决北伐补给难题。启示：工程创新可降低
长期运营成本。

# 七擒七纵

诸葛亮七次擒获孟获又七次释放，最终使其真心归附。启示：收服人心
比消灭对手更重要，耐心与格局决定终局。
